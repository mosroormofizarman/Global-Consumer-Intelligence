# Global Consumer Intelligence (GCI) World 2026

Welcome to my repository showcasing my coursework, assignments, and projects from the **Global Consumer Intelligence (GCI) World April 2026** program. 

This three-month online lecture series, organized by the Matsuo-Iwasawa Laboratory at the Graduate School of Engineering, The University of Tokyo, focuses on the fundamental theories and practical implementations of data science and AI.

## 🧠 About the Program
The GCI program is designed to develop industry-ready abilities by covering the complete data science workflow: from understanding and processing raw data to building, evaluating, and optimizing machine learning models.

## 📁 Repository Structure
The repository is structured logically to track my progression from introductory materials to advanced machine learning concepts and final projects:

*   **`preparatory-materials/`** & **`prelecture/`**: Foundational resources, setup guides, and introductory materials required before the official start of the cohort.
*   **`student-guide/`**: Documentation outlining the program guidelines, academic integrity policies, and instructions for utilizing platforms like Google Colab and Omnicampus.
*   **`session_1` to `session_14`**: Weekly lecture materials, coding exercises, and homework assignments. These sessions cover the full spectrum of the curriculum, from basic Python and statistics to advanced machine learning applications.
*   **`competition/`**: Code and Jupyter Notebooks developed for the hands-on data science competition (sports player draft prediction). This includes feature engineering pipelines, cross-validation strategies, and hyperparameter optimization utilizing **Optuna**, **LightGBM**, **XGBoost**, and **CatBoost**.
*   **`finals/`**: Capstone project materials focusing on a telecom churn and upselling Proof of Concept titled *"Company A Wireless Telecom Smart Plan Migration: Transforming Telecom 'Bill-Shock' into Recurring Premium Revenue via Predictive ML Upselling."*
    *   Includes the complete codebase detailing the end-to-end ML pipeline: merging 100k client and usage records, handling class imbalance, and engineering custom business metrics like `Overage_to_Revenue_Ratio`, `Usage_Dropoff_Rate`, and `Revenue_Per_MOU`
    *   Showcases predictive modeling comparisons, elevating a Baseline Logistic Regression to a Champion XGBoost Classifier that achieved a 97.71% ROC-AUC and 95.68% Average Precision.
    *   Contains the final business proposal slide decks outlining campaign ROI, waterfall financial projections, and risk sensitivity analysis.
*   **`certificate/`**: Digital copies of my academic achievements and completion records from the program.
